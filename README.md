# Production Hub · Agente de Impressão

Instaladores do agente de impressão do Production Hub, para Windows. Aqui não há código-fonte.

**Baixar a última versão:**
[ProductionHub-AgenteImpressao.exe](https://github.com/Nicastrodev/productionhub-agente/releases/latest/download/ProductionHub-AgenteImpressao.exe)

Depois de instalado, o agente se atualiza sozinho a partir das versões publicadas aqui. Cada versão
traz o arquivo `agente-versao.json`, assinado digitalmente: o agente só instala o que tiver a
assinatura do Production Hub.
